Turing Machine Examples
aⁿ bⁿ (Equal a's and b's)
Language: {aⁿ bⁿ | n ≥ 1}
How it works:
1. Mark first 'a' with 'X'
2. Find first 'b', mark with 'Y'
3. Return to start, repeat
4. Accept if all matched
aⁿ bⁿ cⁿ (Three equal groups)
Language: {aⁿ bⁿ cⁿ | n ≥ 1}
How it works:
1. Mark one 'a', one 'b', one 'c'
2. Return to start
3. Repeat until all matched
4. This is context-sensitive!
Palindrome checker
Language: {w | w = wᴿ} (w reads same forwards/backwards)
How it works:
1. Mark first symbol, remember it
2. Go to end, check last symbol
3. If match, mark and continue inward
4. Accept if all symbols match
Binary increment (+1)
Function: Add 1 to binary number
How it works:
1. Go to rightmost bit
2. If 0, change to 1, done
3. If 1, change to 0, carry left
4. Repeat until no carry needed
📈 Beyond Regular Languages

These languages require Turing Machines (they're not regular or context-free):

ww (String repeated twice)
Language: {ww | w ∈ {0,1}*}
Examples: 00, 0101, 110110

Language: {w | #₀(w) = #₁(w) = #₂(w)}
Examples: 012, 102021, 210120
